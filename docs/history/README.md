# History

This directory keeps documents that describe how the code got here, not how
it works today. `fix-plans/` holds the audit fix plans and pull-request bodies
written for the `rskrb5-patched` releases (0.2.1, 0.2.2) and the upstream
`clelange/rskrb5` pull requests; `scratch-log.md` is the upstream `rskrb5`
development log; `publishing.md` and `release-notes.md` are the upstream
`rskrb5` 0.1/0.2 release plan and notes, whose dispatch-based Docker and Active
Directory jobs the rskrb5-ng CI doesn't have. None of these files is
maintained or shipped in the package; the current release procedure is
[`../RELEASING.md`](../RELEASING.md), and [`../../PROVENANCE.md`](../../PROVENANCE.md)
explains the lineage.
